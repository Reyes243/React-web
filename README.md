# Pantallas en React Web (Registro, Login y Bienvenida)

Proyecto base en React (Vite) con tres componentes individuales y manejo de estados mediante `useState`.

## Componentes incluidos

- `src/components/Registro.jsx` — Formulario de registro con captura de nombre, correo, contraseña y confirmación en estado (`useState`).
- `src/components/Login.jsx` — Formulario de inicio de sesión con captura de correo y contraseña en estado (`useState`).
- `src/components/Bienvenida.jsx` — Pantalla de bienvenida que muestra los datos del usuario activo y opciones de navegación.

## Cómo ejecutar el proyecto

```bash
npm install
npm run dev
```
